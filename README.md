# Trabalhos e Estudos — SENAI

Este repositório reúne exercícios e atividades práticas desenvolvidos durante meus estudos de programação no SENAI, em 2022.

Organizei os arquivos por assunto para facilitar a consulta e preservar essa etapa do meu aprendizado.

## Conteúdo

### [Front-end](front-end/)
Páginas em HTML e CSS do projeto educacional **Game Mania**, incluindo uma página inicial e uma tela de login. As imagens e folhas de estilo originais foram mantidas junto aos arquivos.

### [Lógica de programação](logica-programacao/)
Exercícios de JavaScript com estruturas condicionais e atividades de lógica.

### [Anotações de Git](anotacoes-git/)
Anotações pessoais de comandos Git usadas durante os estudos.

## Sobre os arquivos

São trabalhos antigos, preservados como foram feitos na época. Algumas páginas, referências ou funcionalidades podem estar incompletas. O objetivo é registrar minha evolução no aprendizado, e não apresentar aplicações prontas para produção.
